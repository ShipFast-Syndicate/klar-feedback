# Klar — feedback & bug reports

This is the public issue tracker for [**Klar**](https://klar.alphabros.eu), privacy-first
web analytics: no cookies, no fingerprinting, no consent banner.

There's no code here. Klar's source isn't public (yet — that's the direction), so this
repo exists to give you somewhere to tell us when something breaks.

## Report something

- **Something's broken** → [Bug report](../../issues/new?template=bug_report.yml)
- **Something's missing** → [Feature request](../../issues/new?template=feature_request.yml)
- **You're not sure how something works** → [Question](../../issues/new?template=question.yml)

Before opening one, a quick search of [existing issues](../../issues?q=is%3Aissue) often
saves you the typing.

## Please don't post here

- **Security vulnerabilities.** Please don't open an issue — see [SECURITY.md](SECURITY.md).
  A public issue describing a hole in an analytics endpoint is a disclosure, not a report.
- **API keys, site IDs tied to a client, or anything from a customer's dashboard.** Redact
  screenshots. We'd rather have a vaguer bug report than your key in a search index.
- **Account or billing problems** — those need your account, which we can't discuss in
  public. Email `klar-support@alphabros.eu`.

## What happens next

Klar is built by a very small team, so: we read everything, we won't reply to everything
immediately, and we'd rather tell you "not soon" than leave you waiting on silence. If an
issue goes quiet for a while, a nudge is welcome rather than rude.
