## Overview

This repository is Klar's public feedback and bug-report tracker. The README explicitly states that it contains no product code. GitHub supplies the issue interface; the repository supplies report templates, conduct/security guidance and links to Klar.

Klar's application, marketing site and documentation remain the source for Klar's product appearance. This tracker does not establish a second palette, typography system or component library.

## Do's and Don'ts

- Do preserve the README's separate bug, feature and question entry points.
- Do keep product links directed to the existing Klar site and documentation.
- Do follow the README's redaction and private-support guidance for submitted screenshots and account/security issues.
- Don't infer Klar's design tokens from GitHub chrome or uploaded user screenshots.
- Don't describe this issue tracker as an application implementation.
